In progress

Renellence CRM

An in-house CRM to replace HubSpot

Renellence is moving from HubSpot to its own CRM, and I'm building it on a Postgres database. Leads, calls, emails, orders and payments come in through one intake pipeline, and the sales platform works directly with the company's own records.

Data model

A Postgres schema for contacts, clinics, deals, owners, files and change history. HubSpot records are imported with their history.

Intake pipeline

TypeScript functions on Supabase turn payments, orders, ad leads, emails and calls into CRM records through webhooks and scheduled pulls.

Shared write rules

Create, update and link logic lives in database functions, so the app and the intake pipeline write records the same way.

Rep-facing screens

Contact and clinic views, deal boards, tasks, filterable saved lists with CSV export, and Gmail connected through Google sign-in.

Careful migration

It's being built and tested in a separate sandbox alongside the live system, so the switch shouldn't disrupt the sales team.

Testing

Each intake source has its own tests, and the API is tested against an in-memory Postgres database.

  • Serverless Node.js API on Vercel (12 routes, 15K+ lines) with role-based access.

In use

Order-to-cash

Order automation

An n8n workflow that takes an order from intake through to delivery without manual re-entry.

  1. Order intake
  2. Approval by a person
  3. E-signature
  4. QuickBooks invoice
  5. 3PL shipment tracking
  6. Synced back to the CRM

Connects nine services, including HubSpot, Stripe, Shopify, QuickBooks and Meta.

Approach

Things I try to get right

Not losing data

Syncs don't delete anything until a copy is confirmed, and records are deduplicated.

Handling outages

Retries with backoff and cached fallbacks, so the app still works when a service is down.

Testing

About 1,600 assertions across 46 suites, with a local setup that mocks the outside services.

Careful releases

A dry run and a backup before each release, then a check that everything still runs.
